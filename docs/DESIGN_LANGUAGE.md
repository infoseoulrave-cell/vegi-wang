# 베지왕 디자인 언어 (v0.1)

> 로고·네이밍 확정 전 단계. "전체적인 프론트엔드 디자인"의 기준선. Figma 연동 후 이 문서를 그대로 컴포넌트 라이브러리로 옮긴다.

## 1. 브랜드 personality

**"시장의 신선함 × 데이터의 명료함"**

- 신선함: 산지의 채소·과일·수산의 생생함, 아침 시장의 활기
- 명료함: 복잡한 유통·시세를 신호등처럼 단순하게 번역
- 정직함: 소비자 편에서 "지금 사도 되는지"를 숨김없이

톤 & 보이스: 생활 언어로, 쉽고 정직하게. (예: "오늘은 사기 좋은 날", "소매 거품이 큽니다")

## 2. 컬러

| 역할 | 이름 | HEX |
|---|---|---|
| Primary | 베지 그린 | `#1F9D55` |
| Primary Dark | 딥 그린 | `#147A41` |
| Background | 프레시 아이보리 | `#F7FAF5` |
| Ink (text) | 딥 포레스트 | `#14231A` |
| 신호: 저렴(cheap) | Emerald | `#059669` |
| 신호: 적정(fair) | Amber | `#D97706` |
| 신호: 비쌈(expensive) | Rose | `#E11D48` |

- 신호등 3색은 나침반의 정체성 → 절대 브랜드 그린으로 대체하지 않는다.
- 중립 텍스트는 Ink의 투명도 단계(70/60/50/45%)로 위계 표현.

## 3. 타이포그래피

- 본문/제목: **Pretendard**(한국어 우선, 폴백 Apple SD Gothic Neo / Malgun Gothic).
- **가격·숫자는 tabular-nums(고정폭 숫자)** — 표·카드에서 자릿수 정렬 필수.
- 스케일: Display 40/48, H1 32, H2 24, Body 16, Caption 12~13.
- 가격은 굵게(extrabold) + tabular, 단위(원/kg)는 캡션 톤으로 약하게.

## 4. 간격·형태·깊이

- 8pt 스페이싱 스케일(4/8/12/16/24/32...).
- Radius: 카드 `1rem(2xl)`, 배지/버튼 `full`.
- 그림자: 아주 옅게(`shadow-sm`) + `ring-1 ring-black/5`로 경계. 무거운 그림자 금지(신선/가벼움 유지).

## 5. 핵심 컴포넌트

1. **가격 카드**: 상단 품목명/산지·등급·단위 → **경락가(가장 크게)** + 전일 등락 → kg당·평년比 → 회색 박스에 소매가/배수/절약액 → 💡 추천 한 줄.
2. **나침반 배지(신호등)**: 점(dot)+라벨. cheap/fair/expensive 3종.
3. **유통 배지**: 합리적/보통/거품 큼.
4. **카테고리 탭**: 전체/채소/과일/수산, 선택 시 그린 필.
5. **Stat 카드**: 기준일·사기좋은품목·최대절약 등 요약 지표.
6. **시세 테이블(파워 유저용)**: 밀도 높은 표, tabular-nums, 정렬/필터.
7. **알림 CTA/대기자 폼**: 관심 품목 칩 + 이메일. (니즈 DB 시드)

## 6. 레이아웃 원칙

- **모바일 퍼스트**(장보기 맥락 = 모바일). 상단 고정 헤더 + CTA.
- 히어로 → 오늘의 추천/요약 → 경매가 보드 → 알림 CTA → 신뢰(데이터 출처) 순.
- 데이터 출처(가락시장·KAMIS) 명시로 신뢰 확보.

## 7. 모션

- 절제된 마이크로 인터랙션: 가격 갱신 시 숫자 롤업, 배지 페이드, 탭 전환 슬라이드.
- 과한 애니메이션 지양(데이터 신뢰감 유지).

## 8. 현재 코드와의 연결

- 토큰은 `src/app/globals.css`의 `--brand`, `--brand-dark`, `--background`, `--foreground`에 이미 반영. 확장 시 여기에 신호 3색·타이포 토큰 추가.
- 컴포넌트: `src/components/PriceBoard.tsx`, `CompassBadge.tsx`, `WaitlistForm.tsx`가 위 정의의 1차 구현.
