브레인스토밍이 섹션 2·3 승인 직전에서 멈췄다. 아래 §2의 결정 5개는 확정이고,

## 1. 왜 바꾸는가

현재 화면은 도매-소매 차이를 **"거품"**이라 부르고 **"절약액"**을 원 단위로 제시한다.
세 가지가 이 서사를 지탱하지 못한다.

**실측이 받쳐주지 않는다.** 가격 축을 정확히 고친 뒤 재보니 소매÷경락 중앙값은
**1.36배**(n=42)였다. 42개 중 30개가 1.8배 미만이고, 깐마늘은 **0.66배**로
소매가 오히려 싸다. "거품"을 주장할 분포가 아니다.

**검색 수요가 없다.** 네이버 데이터랩 실측(§3)에서 `유통마진` 계열은
`가락시장`의 약 **1/4,800**이었다. 4개 키워드를 묶은 그룹은 아예 **빈 배열**이
반환됐다 — 최소 표시 기준 미달이다.

**계산하지 않은 비용을 부정한다.** 도매-소매 사이에는 물류·선별·소분·저장·
폐기(농산물 20~30%)·임대료·인건비가 있다. 우리 모델에 이 중 하나도 없다.
게다가 임계값 1.8/2.5는 **축이 깨져 있던 시기에 정해진 값**이다.

> 메타데이터는 처음 방향을 지키고 있었다.
> `title`이 이미 "오늘 아침 농수산물 경매가, 사기 좋은 날인지 알려드립니다"다.
> **되돌리는 작업이 아니라 본문을 제목에 맞추는 작업이다.**

## 2. 확정된 결정

| # | 결정 | 비고 |
|---|---|---|
| 1 | **핵심 행동 = 살 시점 미루기/당기기** | 분위(percentile)와 추세가 주인공 |
| 2 | **거품배수·절약액을 홈에서 완전히 제거** | 품목 상세로 이사, 문구 중립화 |
| 3 | **판정 불가 품목은 홈 목록에서 숨김** | 두 칸 목록에 한정 |
| 4 | **판정 조건 = 최근 21일 안에 10일 이상 관측** | 개수와 최근성을 함께 건다 |
| 5 | **그래프는 판정과 무관하게 보여준다 (안 A)** | 곡선은 관측, 분위는 추론 |

결정 5의 근거: 곡선은 우리가 실제로 받은 값을 그린 것이라 주장이 없다.
"고가권"은 그 값들로 끌어낸 판단이고 표본이 얇으면 틀린다.
**사실을 숨기는 것과 판단을 유보하는 것은 다른 일이다.**
SEO 관점에서도 상세 페이지에 실제 콘텐츠(그래프)가 있어야 색인된다.

## 3. 근거 데이터 (네이버 데이터랩, 2026-07 기준)

```
가락시장                       91.3
오늘 배추값·사과 가격·마늘 가격   3.27
농수산물 가격·도매시장 가격      0.68
유통마진                       0.019
경매가                         0.012
```

계절성이 갈린다.

| 키워드 | 2025-11 | 2026-04 | 진폭 |
|---|---|---|---|
| 배추 가격 | 55.9 | 0.91 | **62배** |
| 가락시장 | 94.7 | 77.8 | **1.2배** |

**"배추 가격"류는 김장철 몰빵**이고, **"가락시장"은 연중 평평하다.**
마케팅 문구는 "오늘의 가락시장 경매가를 확인해보세요" 뉘앙스로 간다.

주의: `가락시장` 검색에는 위치·영업시간·가락몰 쇼핑 의도가 섞여 있어
전부가 가격 수요는 아니다. 방향만 신뢰한다.

## 4. 설계

### 4.1 판정 게이트 — 승인됨

`src/lib/trend.ts`에 함수 하나를 추가한다.

```
canJudgeTiming(series, asOfDate) → { ok, observedDays, windowDays }
```

- 창의 기준점은 **시리즈 끝이 아니라 오늘**. 7/3~7/7만 있고 최근이 빈 품목은
  "총 5일"이 아니라 "최근 21일 안에 0일"로 걸러져야 한다.
- **이월된 오늘은 관측으로 세지 않는다.** 시리즈에는 이월일 때도
  `{date: 오늘, label:"오늘"}`이 붙는데, 그걸 관측으로 치면 주말마다 표본이
  공짜로 늘어난다. 어제 값을 다시 쓴 것이지 새로 잰 게 아니다.
- 실패 시 `trendBasis = "none"`. 기존 배관이 그대로 받아 분위·포지션·추천이
  전부 나가지 않는다. **`compass.ts`의 `withSignal` 한 곳만 고친다.**

게이트는 **판정에만** 걸고 **표시에는 걸지 않는다**(결정 5).
`FeaturedChart`의 필터를 `trendBasis === "series"`에서 **점 2개 이상**으로 완화한다.

### 4.2 화면 변경 — 미승인

**홈에서 빠지는 것**

| 대상 | 이유 |
|---|---|
| `SavingsBasket` | `savingPerKg` 기반. 경락가는 중도매인 매입가라 소비자가 실현 불가 |
| 히어로 "절약 최대 ○○원" | 같은 이유 |
| 카드 `RetailGapBadge` | 계산하지 않은 비용을 부정하는 판정 |
| 카드 "소매 약 ○○원 · 절약률 ○○%" | 상세로 이사 |

**홈에 남거나 올라오는 것**

- **두 칸 목록** — `TodayPicks`를 개조해 상단으로. 게이트 통과분만.
  품목마다 관측일수를 적는다("21일 중 18일 관측").
- **시세 그래프** — `FeaturedChart` 유지, 필터 완화.
- **카드** — 가격 + 분위 + 관측일수 + 이월 라벨.

**상세로 이사하는 것**

```
지금   소매 거품 큼 · 소매의 0.42배 · 1개당 0원 절약
바꿈   소매가 대비 2.5배
       └ 물류·선별·폐기·임대료가 포함된 값입니다
```

깐마늘 0.7배(소매가 더 쌈)처럼 배수 자체는 버릴 정보가 아니다.

**문구와 검색**

- 홈 `title`·`description`은 **이미 맞으므로 건드리지 않는다.**
- 품목 페이지: `배추 가격 동향 — 베지왕` → `배추 오늘 경매가 — 가락시장 도매 시세 | 베지왕`
- `items/[id]`가 `force-dynamic`이다. 검색 착륙지가 매 요청 서버 렌더면
  크롤링 효율과 비용 양쪽에서 손해다. **ISR + `generateStaticParams`로 전환**
  (범위 포함 여부는 §5 미결).

### 4.3 실패 모드와 테스트 — 미승인

**반드시 처리할 상태**

- **게이트 통과 0종** — 오늘 실제로 이 상태다(§6). 백지로 두지 않고
  얼마나 모였고 언제부터 판정 가능한지 밝힌다.
  > 아직 타이밍을 판정할 만큼 이력이 모이지 않았습니다
  > 36종 수집 중 · 최근 21일 안에 10일이 모이면 판정을 시작합니다
- **한쪽만 0종** — 칸을 지우지 말고 문장으로 채운다. 빈 칸은 고장으로 읽힌다.
- **이월된 오늘** — 관측일로 세지 않되 판정 대상 가격은 이월값이다.
  둘을 헷갈리면 주말마다 표본이 부풀거나 오늘 값이 사라진다.

**테스트**

- `canJudgeTiming` — 창 밖 데이터만 있을 때 실패 / 이월 오늘 제외 /
  경계값 9일·10일 / 같은 날 중복 제거
- **회귀(핵심 불변식)** — 게이트 실패 시 `trendPercentile`·`trendPosition`·
  `recommendation`이 응답에 실리지 않는지
- 렌더 — 통과 0종일 때 홈이 깨지지 않는지

## 6. 재개 시 알아야 할 현재 상태

**데이터**

- 자체 이력 6~9일치, 30일 폭에 흩어짐 (7/3~7/7 + 7/28~8/1, 가운데 3주 결측)
- **어떤 품목도 10일치가 없다.** 게이트를 켜면 오늘은 통과 0종
- 백필이 가락 API 일일 한도로 중단됨. 한도 회복 후 **7/8~7/27을 마저 채우면
  ~21영업일치**가 되어 대부분 통과할 것으로 예상

**알아야 할 오탐 (먼저 고칠 것)**

`/api/health`의 `ingestHealth`가 지금 `alert`인데 **오탐이다.**
`repos.ingestRuns.latest(14)`가 **실행 시각 순**으로 가져오는데, 백필로 과거
날짜를 돌리면 그 기록이 최근 14건을 차지한다. 그 안에 7/14~7/27 빈손이 줄줄이
있어 "14일 연속 실패"로 읽힌다. 실제 일일 파이프라인은 정상이다.

고치는 법: `assessIngest`에 넘기기 전에 **최근 sale_date 기준으로 추린다**
(예: `saleDate >= today - 21`인 것만). 백필이 정상 운영을 실패로 만들면
알림 신뢰가 무너진다 — 이 알림을 만든 이유가 바로 그거였다.

**미해결 관측**

카드 다수에 "소매가 미확인 — 소매 조사가가 없어 유통 거품을 계산하지
않았습니다" 가 뜬다. KAMIS 소매가 해당 품목에 매칭되지 않는다는 뜻.
서사 전환으로 홈에서는 사라지지만 **상세 페이지에서는 그대로 남으므로**
별도 확인이 필요하다.
