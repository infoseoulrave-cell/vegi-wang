## 문제

신선식품 가격 변동은 큰데, 소비·매입 주체는 “지금 사도 되나?”를 감·연평균으로 판단한다. 단위(상자/근/개)도 제각각이라 비교가 어렵다.

## 솔루션

1. 가락 경락가 일별 수집 → 원/kg 표준축 정규화  
2. 최근 21일 중 10일 이상 관측 시에만 분위·타이밍 판정  
3. 담기 / 관망 UX + 품목 그래프 + 얼리 액세스 알림  
4. A: 시세·타이밍 SaaS → B: 시세 연동 선별 SKU 통신판매(단계)
